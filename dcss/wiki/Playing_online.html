オンラインで遊ぶ

DCSS をオンラインで遊べるサーバーがいくつかあり、ブラウザ(WebTiles)か、SSH/telnet で遊べる。

オンラインで遊ぶと、特に IRC のチャットルームに参加した場合、おもな利点が三つある。

  • ほかの人にプレイを生で観戦してもらい、メッセージや助言を送ってもらえる(よく無視される「hit _」の表示がそれだ……)。
  • 同じ組み合わせばかり遊んでいても、倒しに行くプレイヤーの幽霊が、より楽しく多彩な顔ぶれになる。
  • 調べ方さえわかれば、どのマイルストーンや死亡のリプレイでも見られる。どこで間違えたかを振り返ったり、笑える場面をもう一度味わったりするのにうってつけだ。

サーバー

今すぐオンラインで Crawl を遊ぶ

北アメリカのサーバー

  • CAO - アリゾナ州。0.10 から 0.28 までの全バージョンと trunk がある。
  • CBR2 - オハイオ州。0.26 から 0.28 までの全バージョンと trunk がある。
  • CKO - ニューヨーク州。0.18、0.21 から 0.28 までの全バージョン、trunk がある。

ヨーロッパのサーバー

  • CDO - ドイツ。0.10 から 0.28 までの全バージョンと trunk がある(コンソールのみ)。
  • CUE - オランダのアムステルダム。0.10 から 0.28 までの全バージョンと trunk がある。
  • CXC - フランス。0.14 から 0.28 までの全バージョンと trunk がある。

アジアのサーバー

  • CWZ - 韓国。0.11 から 0.28 までの全バージョンと trunk がある(WebTiles のみ)。
  • LLD - 日本。0.13 から 0.28 までの全バージョンと trunk がある(WebTiles のみ)。

オーストラリアのサーバー

  • CPO - シドニー。0.16 から 0.28 までの全バージョンと trunk がある(WebTiles のみ)。

WebTiles

WebTiles は、DCSS の中でも手軽に始められ、グラフィックも凝った版だ。Chromium などのたいていの最近のブラウザなら、手順は簡単だ。サーバーのサイト(上のリンク)に行き、アカウントを作って遊び始めるだけでいい。個人情報を入力する必要はなく、メールアドレスもパスワードを忘れたとき用の任意の項目だ。

コンソール

コンソール版は、遊ぶのに SSH クライアントが要るので、たいてい準備がもっと面倒だ。Mac や Linux なら SSH はたぶん最初から入っているが、Windows でコンソール版をちゃんとオンラインで遊ぶには、PuTTY というプログラムをダウンロードする必要がある。

SSH での接続の手引きはこちらにある。そのすぐ上にはサーバーとその SSH 鍵の一覧もある。

設定

動作が重いと感じたら、SSH の圧縮を有効にするのを忘れずに! キーボードがきちんと動くよう、NetHack モードにするのも忘れずに! これによってテンキーで入力される文字が実質的に変わるので、数字の段のキーとテンキーとでは、入力されるパスワードが違ってしまう点によく注意すること(CAO に接続したあと、ログインして遊ぶとき)。先の手引きに書かれていないこととして、Terminal->Features で「Disable Application keypad mode」を設定できる。これで +-=/ を使って標的を切り替えられるようになる。今のところ、テンキーの 5 で長い休憩をとれるようにする方法はない。現状、オンラインで長い休憩をとるには、数字の段の 5 を押すしかない。

多くの人は文字セットを変えて、壁をもっと「詰まった」見た目にしたり、ポータルや店がワンドや杖のように見えないようにしたりしている。そうするには、設定に「char_set = IBM」という行を足し、PuTTY の Window->Translation->Received data assumed to be in which character set で文字セットを CP437 にするだけでいい。

Gnome や KDE のデスクトップ、そのほか UTF-8 に対応した端末では、「char_set = unicode」でそれを有効にでき、見た目がより良くなる。

端末の色パレットを、タイル版の「公式の」パレットに合わせたい人もいるだろう。 設定する色は次のとおり。 

    VColour(  0,   0,   0), // BLACK
    VColour(  0,  82, 255), // BLUE
    VColour(100, 185,  70), // GREEN
    VColour(  0, 180, 180), // CYAN
    VColour(255,  48,   0), // RED
    VColour(238,  92, 238), // MAGENTA
    VColour(165,  91,   0), // BROWN
    VColour(162, 162, 162), // LIGHTGREY
    VColour( 82,  82,  82), // DARKGREY
    VColour( 82, 102, 255), // LIGHTBLUE
    VColour( 82, 255,  82), // LIGHTGREEN
    VColour( 82, 255, 255), // LIGHTCYAN
    VColour(255,  82,  82), // LIGHTRED
    VColour(255,  82, 255), // LIGHTMAGENTA
    VColour(255, 255,  82), // YELLOW
    VColour(255, 255, 255)  // WHITE

PuTTY の場合: 

    RGB(  0,   0,   0), // ANSI BLACK
    RGB(  0,  82, 255), // ANSI BLUE
    RGB(100, 185,  70), // ANSI GREEN
    RGB(  0, 180, 180), // ANSI CYAN
    RGB(255,  48,   0), // ANSI RED
    RGB(238,  92, 238), // ANSI MAGENTA
    RGB(165,  91,   0), // ANSI YELLOW
    RGB(162, 162, 162), // ANSI WHITE
    RGB( 82,  82,  82), // ANSI BLACK BOLD
    RGB( 82, 102, 255), // ANSI BLUE BOLD
    RGB( 82, 255,  82), // ANSI GREEN BOLD
    RGB( 82, 255, 255), // ANSI CYAN BOLD
    RGB(255,  82,  82), // ANSI RED BOLD
    RGB(255,  82, 255), // ANSI MAGENTA BOLD
    RGB(255, 255,  82), // ANSI YELLOW BOLD
    RGB(255, 255, 255)  // ANSI WHITE BOLD
