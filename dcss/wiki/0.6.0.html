Stone Soup 0.6 (20100326)

おことわり: ここに挙げるのは主な変更だけで、すべての変更を網羅したものではない。

0.5 のセーブデータとは互換性がない。

重要: バグトラッカーは http://crawl.develz.org/mantis/ に移った。バグの報告や意見はすべてそちらへ。よろしく!

公式サイトは http://crawl.develz.org/wordpress/ に移った。お知らせや開発の変更点はそちらに載せる。

ソースコードは今も SourceForge に置いているが、バージョン管理には git を使うようになった。詳しくは docs/develop/git/quickstart.txt を参照。


0.6 の主な変更

  • 呪文の系統から占術を削除した。
  • 新しい神が3柱: ジーヴァ、フェダス、ケイブリアドス。
  • 迷宮の神の祭壇が、寺院ではなく迷宮:2〜9 に現れることがあるようになった。
  • 水辺の新しい分岐: 浅瀬。沼か蛇穴の代わりに現れることがある。
  • AC/EV の仕組みを作り直した。特に、器用が EV に与える効果に上限がなくなった。(AC の弱体化を参照)
  • 腕力が持てる重さに与える影響が、ずっと大きくなった。
  • スライムと醜きものが、より面白く、より危険になった。
  • かっこいい新しいモンスター、ポータルヴォールト、矢弾のブランドがたくさん加わった。

神

  • 新しい神: スライムの神ジーヴァ。
  • 新しい神: 植物と菌類の神フェダス。
  • 新しい神: 緩慢の神ケイブリアドス。
  • 諸宗派の寺院の祭壇の数が、ランダムに6〜14になった。
  • 諸宗派の寺院に祭壇のない迷宮の神は、迷宮:2〜9 に必ず祭壇が置かれる。
  • 死体を捧げるのに、祈ってから切り分ける('pc')必要はなくなり、祈る('p')だけでよくなった。
  • エリヴィロンは、祈りの最中に死体を解体しても気にしなくなった。
  • ルゴヌの「階層の崩壊」は、1つの階で1回しか使えなくなった。
  • キクバークッグァが苦痛への耐性を授け、死体と苦痛のブランドを与えるようになった。
  • ルゴヌの「階層の崩壊」で出てくるモンスターは、すべて中立になった。
  • シフ・ムーナは、呪文を1つも覚えていない者を信者として受け入れなくなった。
  • 輝けるものの怒りによるダメージがずっと小さくなった。
  • 輝けるものの光輪のせいで、プレイヤーが攻撃を受けやすくなることはなくなった。
  • ヴェフメットが破壊呪文の MP コストを下げ、射程を延ばすようになった。
  • 経験値の少ない信者に対しては、ゾムがアビスへの追放や敵対モンスターを手加減するようになった。
  • ゾムが、死んだプレイヤーをまれに生き返らせることがある。
  • イレデレンヌルから授かったしもべは、ゾンビの後ろにいても階段をついてくるようになった。
  • ジンがプレイヤーを病気、腐敗、瘴気から守るようになった。
  • ジンの「説法の朗読」は満腹度を消費しなくなり、モンスターをバーサークさせることもなくなった。

階層

  • 新しい分岐: 浅瀬。ギリシャ神話を下敷きにしていて、水棲の民、潮の満ち引き、カメが登場する。ゲームごとに、浅瀬、蛇穴、沼のうち2つが選ばれて現れるようになった。
  • 獣の棲み処を8階に縮めた。
  • 獣の棲み処と沼の階の構造を、より面白くした。
  • 新しいポータルヴォールト: 濠城、宝の埋蔵庫、火山、魔術師の研究所。
  • 脱出ハッチの一部を、(1回きりの)縦穴に置き換えた。
  • 新しい壁の種類「樹木」。2本並ぶと視線をさえぎる。
  • プレイヤーがオーブを拾ったときに封じるのを、地獄の入り口ではなく地獄へのポータルにした。
  • ユニークが出られる分岐の制限をゆるめた。
  • スライムの穴ぐらには、機械仕掛けの罠を置かないようにした。
  • 警報の罠は1〜3回しか作動しないようにした。
  • HP が罠の最大ダメージより少ないときは、罠を解除する前に確認を求めるようにした。
  • 地獄、巣、沼、宝物庫の最下層に、新しい別のバージョンを加えた。
  • パンデモニウムの君主の階では、特別な告知が出るようになった。
  • すべてのポータルヴォールトと、パンデモニウムの君主の階にマイルストーンを加えた。
  • 新しいヴォールトが多数。

遠隔戦闘

  • ハンドクロスボウとダーツのスキルを削除した。吹き矢筒は投擲スキルを使うようになった。
  • 新しい職業: 秘術の射手。聖戦士、転位術師、狩人を組み合わせたものだ。
  • 新しい矢弾の素材: 銀、鋼。
  • 新しい矢弾のブランド: 離散、電撃、爆発、貫通、刈り取り。
  • 新しい吹き矢針のブランド: 睡眠、減速、麻痺、混乱、凶暴化、病気。
  • ブランドや強化値のついた矢弾は「ルーンが刻まれた」と表示される。
  • ブランドをつける呪文が、射撃武器にも効くようになった。
  • 射撃武器の護りのブランドは、EV+5 を与える回避のブランドに置き換えた。
  • ネッソスを除き、火炎の射撃武器では毒の矢弾を使えなくなった。
  • 毒の矢弾の呪文を削除し、毒の武器と一時的なブランドに任せることにした。
  • 矢弾がまとまりやすくなった。
  • ブランドのついた矢弾が壊れる確率を下げた。
  • 毒の矢弾の効き目が強くなった。
  • 殺戮の指輪が射撃武器にも効くようになった。
  • 狩人の初期の矢弾は +1 になった。スリングを持って始める狩人は、バックラーも持っている。
  • スリングは片手持ちになり、盾で攻撃が遅くならなくなった。
  • 石の重さが3倍になった。

アイテム

  • 減速耐性の護符を削除した。
  • 軽い防具と重い防具の区別をなくした。
  • 静寂の巻物を加えた。
  • 知性の薬と敏捷の薬を加えた。
  • 反射の盾を加えた。
  • 新しい護符: 守護霊、信仰、停滞。
  • 明晰の護符が、意図しないバーサークを防ぐようになった。
  • ゴールドドラゴンの鎧の AC を下げた。
  • ランダムアーティファクトの武器には、必ずブランドがつくようになった。
  • 早業のブランドがランダムにつくのは、アーティファクト、短剣、棒術の武器だけになった。
  • ヴォーパルのブランドのダメージボーナスを、半分の12.5%にした。
  • 防具の獲得で、胴以外の部位の防具が出やすくなった。
  • 神によらない獲得は、すでに見たことのある防具や武器を避けるようになった。
  • 呪文を専門とするキャラクターには、本の獲得で虎の巻が出なくなった。
  • 獲得の選択肢にワンドを加えた。
  • 耐性の薬の効果が長く続くようになった。
  • 神罰の武器は呪われなくなった。
  • 鞭と悪魔の鞭を改良した。悪魔の鞭は輝けるものに祝福してもらえる。
  • 能力値の特性を1つしか持たないアーティファクトが出にくくなった。
  • 電撃の武器は、水の中では放電するようになった。
  • アーティファクトから、発動できる特性の一部(地図作成・テレポート)を削除した。
  • +Lev のアイテムを外すと浮遊が解けるようになり、水の上では外せなくなった。
  • 棍棒とスピアに、急所攻撃のほどほどのボーナスがつく。
  • 棍棒で急所攻撃に成功すると、相手を気絶させることがある。
  • 吸血の武器は満腹のときにしか構えられず、構えていると空腹になる。
  • ミイラとグールは、吸血の武器で回復しない。
  • 盾は +3 まで強化できる。
  • ロッドは構えると鑑定され、鈍器スキルを使うようになった。
  • ロッドの再充填は、プレイヤーの MP や、所持品に入っているかどうかに左右されなくなった。
  • ロッドを強化すると、再充填が速くなる。
  • 同じ種類の肉は、古さが近ければまとまるようにした。
  • 深い水脈はアイテムを壊さなくなった。溶岩が壊すのは燃えるものだけになった。
  • 一時的に歪曲のブランドがついた武器は、外してもダメージを受けたりアビスへ追放されたりしない。
  • ルーン、ゾットのオーブ、使っていないゲリュオンの角笛は捧げられないようにした。
  • 呪われていたアイテムには、自動で {was cursed} の銘を刻む。

モンスター

  • 浅瀬の新しいモンスター: 水棲の民・人魚、セイレーン、ハーピー、クラーケン、カメ、サメ。
  • 新しいモンスター: 放出菌糸。巨大胞子から生まれ、巨大胞子を生み出す。
  • そのほかの新しいモンスター: からかさキノコ、シクスファルハイ、黄金の眼球、大ヒル。
  • 新しい植物: 藪。射撃は通り抜けるが、2つ以上並ぶと視線をさえぎる。
  • (甚だしく)醜きものは、色によって耐性と攻撃の追加効果が決まるようになった。
  • スライムは通路で合体し、より大きく強くなる。
  • 幽体はすべて、また階段を使えるようになった。
  • モンスターの説明に、魔法(あるいは「敵対的な魔法」)への耐性を表示するようにした。
  • モンスターの経験値を、強さに見合ったまともな値にした。
  • OOD(その深さには場違いな)モンスターは、その階で長いターンを過ごすまで群れで出てこなくなった。
  • 1つの階で過ごす時間が長くなると、OOD のモンスターが急に出やすくなる。
  • 地獄とゾットの領域を除く迷宮の主な分岐では、どの階でも、その階で過ごす時間が長くなるほどモンスターが湧きにくくなり、最後にはまったく湧かなくなる。
  • オーブを持っての脱出の最中に湧く悪魔は、自分からプレイヤーを探しに来る。
  • ヒドラは、攻撃中の相手が死ぬと、残りの攻撃を新しい相手に向ける。
  • プレイヤーがテレポートで逃げると、モンスターはプレイヤーの位置を忘れるようにした。
  • プレイヤーがしばらくその階を離れていると、モンスターは眠りやすくなる。
  • モンスターの呪文「瞬間退避」と「瞬間接敵」を作り、使わせるようにした。
  • 見つかってはいてもまだ開けられていない隠し扉は、頭の悪いモンスターには知られないままになる。
  • モンスターが怪力の薬と狂戦士の薬を飲むことがある。
  • 熊はバーサークする。心を持たないモンスターはバーサークできない。
  • 混乱したモンスターは、でたらめな方向にワンドを振る。
  • 巨大トカゲはクロコダイルという名前になり、水陸両生になった。
  • 水に潜れるモンスターの数を大きく減らした。
  • 潜っているモンスターは、狙うことも、光線を当てることもできなくなった。
  • 潜っているモンスターは、攻撃できるときは必ず浮かび上がる。
  • 水陸両生の生き物は、水の中で攻撃にボーナスを得なくなった。
  • モンスターの透明感知は、透明なモンスターにはよく効き、透明なプレイヤーにはあまり効かなくなった。
  • 飢えた幽霊が死体を食べる。
  • 混乱したモンスターは、でたらめな方向にワンドを振る。
  • 植物や菌類を殴っても、戦闘と徒手格闘はレベル1までしか上がらない。
  • かっこいい新しいユニークがいくつか。
  • ユニークのせりふがずっと多彩で面白くなった。
  • いくつかのモンスターの記号を変えた。052_monster_glyphs.txt を参照。

キャラクター

  • AC/EV の仕組みを作り直した。
  • 甲冑・躱し身・隠密のスキルの上がり方は、装備の重さで決まる。
  • 腕力が持てる重さに与える影響が、大きく増えた。
  • 持てる重さの基本の値は、プレイヤーの種族の体重で決まる。
  • 放浪者を作り直し、ずっと強くした。
  • ミイラの初期の能力値を上げた。
  • 初期の能力値と装備は、ランダムに決まらなくなった。
  • レベルアップで増える HP と MP は、ランダムでなくなった。
  • 多くの状態異常や効果の持続時間を、ターン数ではなく経過時間で数えるようにした。
  • スキル適性をすべて10の倍数に丸めた。
  • プレイヤーの属性耐性によるダメージ軽減を弱めた。
  • 気をそらしている相手への急所攻撃が起きやすくなったが、そのダメージボーナスは下がった。
  • 戦うと、与えたダメージ、武器の種類、ブランドに応じた騒音が出る。
  • 瘴気への耐性を、負のエネルギーへの耐性から切り離した。腐敗への耐性があれば、病気と瘴気の両方にも耐性がある。
  • 再生で空腹が進むのは、実際に回復している間だけになった。
  • 盾の値 SH が、そのまま防御の確率を表すようになった。
  • 地獄の業火は AC を無視するようになり、そのぶんダメージを抑えた。
  • 魔法の地図作成の変異を、常に働くものに変えた。
  • 焼夷の炎は透明化を打ち消す。
  • 吸血鬼は、(c) の解体ではなく、(a) の特殊能力で血を瓶に詰めるようになった。
  • バーサークすると、0.5 より前と同じく HP が150%になる。
  • 時間の値があふれて一周するのを防ぐため、約2億ターンの時間制限を加えた。

インターフェース: 迷宮の探索

  • アビスで、視界の中のマスへ 'x' やマウスのクリックで自動移動できるようにした。
  • 自動移動は角を斜めに突っ切らず、待ち伏せを避けようとする。
  • 注意対象を、視界に基づくものに切り替えた。
  • 視界の中の注意対象は 'xe' で設定・解除できる。
  • 注意対象を概要画面('Ctrl-O' コマンド)に表示する。
  • Ctrl-O で、まだ見つけていない分岐の入口がありうる範囲を一覧にする。
  • 概要画面('Ctrl-O')に、すべての分岐の探索済みの深さを表示する。
  • 自動で設定された注意対象は、もとになったモンスターがいなくなれば解除される。
  • 迷宮そのものが出す危険な雲(「霧発生装置」)は、プレイヤーが見ると自動で注意対象になる。
  • 隣にいないミミックは、休息や自動移動では安全なものとして扱う。
  • 'X' の階のマップで '[' と ']' を押すと、ほかの階のマップを見られるようにした。
  • 'X' のマップに、階の地形(階段、門、祭壇など)を一覧で表示する。
  • 飢餓状態のときは、自動探索と休息をできないようにした。
  • ラビリンスでは自動探索を使えなくした。

インターフェース: そのほか

  • 仲間に向けてワンドを使っても確認が出なかったのを直した。
  • 買い物リスト('$')を加えた。リストに入れたアイテムを買えるだけのお金がたまると知らせてくれる。
  • 呪文の記憶の新しい画面では、持っている魔法書に載っている呪文がすべて一覧になる。
  • 照らし出された透明なモンスターを倒すと、自動拾いがまたオンになる。
  • 特に狙いをつけるときに、メッセージが大量に出るのを大きく減らした。
  •  !a の銘を加えた。このアイテムを構えて攻撃するときに確認を求める。
  • 新しい Lua ファイル autofight.lua。いちばん近い敵を自動で攻撃できる。
  • -TELE のときのテレポートの試みの一部を、ターンを失わずに取りやめるようにした。
  • 食べ物が自動で 'e' の枠に、薬が 'q' や 'y' の枠に割り当てられることはなくなった。
  • 蒸発の呪文を覚えていると、薬の説明に、その薬から出せる雲を表示する。
  • 未鑑定のアーティファクトも「Ctrl-F artefact」で探せるようになった。
  • 解体するときは、手袋を外すより解体用の道具に持ち替えるほうを優先する。
  • Mac 版で、端末が対応していれば8色より多くの色を使えるようにした。
  • Dvorak 配列用の vi キーの割り当てを用意した。dvorak_command_keys.txt を参照。
  • vi キーを「Unknown command」で上書きできるようにした。no_vi_command_keys.txt を参照。
  • 経験値プールの表示に、たまり具合に応じて色をつけた。
  • docs/ ディレクトリに HTML 版の FAQ を加えた。

呪文

  • 占術の系統を削除した。
  • 新しい呪文: 破壊の爆裂球。目標を追いかけて爆発する。
  • 静寂の範囲は、時間がたつにつれて狭くなる。
  • 有益でない呪文を自分に向けて唱えようとすると、必ず確認を求める。
  • 小動物の召喚で呼べるのは、1回につき最大2匹にした。
  • 小動物の召喚で、緑ネズミやオレンジネズミは出なくなった。
  • 毒素の矢のダメージのうち、耐性で防げない部分を60%から30%に減らした。
  • 行き先をある程度指定できる瞬間移動を使うと、発光するようになった。
  • 豊潤なる蒸留の結果は死体の種類だけで決まるようになり、乱数や腐り具合の影響はなくなった。死体が1つしかないときは確認も出ない。
  • ツキマーの舞踏で動かす武器の強さは、呪文の威力と武器の重さで決まる。
  • レイスの召喚を、打擲型の召喚呪文である招霊に置き換えた。
  • 方向を指定する呪文のうち付与系でないものは、何かに当たると騒音を出す。
  • 呪文を唱えると騒音が出る。
  • 呪文の失敗の効果と地獄の効果も騒音を出す。
  • 犬族のしもべの召喚で呼ぶ犬は、必ず味方になる。
  • 凝結の盾の効果が上がった。
  • 壁の透過の操作を改良した。
  • ミイラもおぞましきものの召喚を唱えられるようにした。
  • 氷の躯なら深い水脈を泳げる。溺れないよう気をつけて!
  • 分解はほんとうに派手に散らかる。
  • 呪文の説明に、今の威力、射程、満腹度のコストを表示する。
  • 呪文のメニューで、役に立たない呪文や禁じられた呪文に色をつける。

タイル版

  • 所持品と、クリックで使える呪文の表示を切り替えるタブを加えた。
  • ミニマップを Shift-Left-Click すると自動探索を始める。
  • プレイヤーのタイルの編集画面('-' コマンド)を復活させた。
  • データベースの検索(?/)を含め、ずっと多くのメニューでタイルを表示する。
  • モンスターやプレイヤーを左クリックするときの、新しい修飾キー:
    • Shift-Left-Click: セットした矢弾をモンスターに撃つ。
    • Ctrl-Left-Click: 目標(モンスターかプレイヤー)に呪文を唱える。
    • Alt-L-Click/Ctrl-Shift-L-Click: 目標(モンスターかプレイヤー)にワンドを振る。
    • 使える場合は、リーチの届く範囲のモンスターを左クリックすると攻撃する。
  • プレイヤーのタイルに HP と MP のバーを加えた。
  • バーサークしているモンスターを示すアイコンを加えた。
  • 肉や死体を食べたときの効果を示すアイコンを加えた。
  • 防具のエゴのアイコンを加えた。
  • 正体のわかったミミックには、宙を舞う武器のアイコンを使い回す。
  • モンスターや地形のタイルを多数、追加・改良した。
  • 画面を描き直すときのアニメーションをいくつか加えた。
  • ヴォールトで、地形やモンスターに独自のタイルを指定できる。
  • コンパイルのときに、タイルの色を動的に変えられる。
  • 同じ組のタイルの変種に、出やすさの重みをつけられる。
  • 入力を待っているときは、マウスを重ねたときの説明をメッセージ欄に出さない。
  • マップとデータベースを読み込む前に起動画面を描き、読み込みの進み具合を表示する。
  • タイルの依存関係を正しく扱い、必要に応じてタイルシートを作り直す。
  • 浅瀬の分岐は、なめらかな階の見た目を試す場にしている。

オプション

  • 変更: clear_messages = false。(以前は delay_message_clear = false。)
  • 新規: explore_delay = -1 オプション。自動探索の遅延を、自動移動の遅延と別にする。
  • 新規: autoinscribe_cursed = true。呪われていたアイテム用。
  • 新規: msg_condense_short = true。短いメッセージを1行にまとめる。
  • 新規: show_more = true。clear_messages と組み合わせると、メッセージ欄がいっぱいのときに -More- を出す。
  • 新規: small_more = false。true にすると、メッセージ欄が1行増える。
  • 新規: msg_min_height = 7。メッセージ欄の最小の大きさを決める。
  • 新規: messages_at_top = false。メッセージをメインのマップの上に表示する。
  • 新規: explore_stop_pickup_ignore。正規表現に合うアイテムは、拾っても自動移動を止めずに続ける。
  • 新規、ASCII 版のみ: use_fake_player_cursor = false。プレイヤーの記号を強調する。
  • 新規、タイル版のみ: tile_show_minihealthbar = true。プレイヤーのタイルに HP のバーを描く。
  • 新規、タイル版のみ: tile_show_minimagicbar = true。プレイヤーのタイルに MP のバーを描く。
  • 新規、タイル版のみ: tile_show_demon_tier = true。悪魔の等級のアイコンを表示する。
  • 新規、タイル版のみ: tile_better_transparency = false。水のマスクをきれいにする。
  • 新規、タイル版のみ: tile_peaceful_col = lightred。友好的なモンスターの色。
  • 新規、タイル版のみ: tile_force_overlay = false。メッセージを重ねて表示する。
  • 新規、タイル版のみ: tile_runrest_rate = 100。休息中の画面の更新頻度。
  • explore_stop の新しい選択肢: greedy_pickup_smart、greedy_pickup_thrown。
  • 名前の変更: unix の 'background' オプションを 'background_colour' にした。
  • 名前の変更: キャラクターの 'job' オプションを 'background' にした。
  • 削除: target_los_first、target_oos、target_wrap、target_zero_exp。

主なバグ修正

  • 分岐の最下層が、まれにルーンなしで作られるのを直した。
  • 能力値を変える装備のせいで、能力値がときどき永久に減ったり増えたりするのを直した。
  • 視界が対称になり、さまざまなバグが直った。
  • ルーンやオーブを拾ったあと、テレポート制御がときどき有効にならないのを直した。

技術的な改善

  • 視界のコードを作り直して改良した。少しだけ見通しのよい、新しい視界のモデルも入っている。
  • 狙いをつけるコードを作り直して改良した。
  • メッセージ欄とメッセージ履歴のコードを書き直した。
  • Lua で書いた自動テストをいくつか加えた。
  • makefile を新しくして改良し、xcode と msvc のプロジェクトを更新した。
  • 大きな .cc と .des のファイルをいくつか、小さなファイルに分けた。
  • マップ作りなどで Lua をずっと強力に使えるよう、Lua のラッパーを多数加えた。
  • ウィザードモード用の Lua REPL。
  • ユニークを置くコードを Lua に移し、uniques.des で制御するようにした。
  • モンスターにプロパティのハッシュを加え、いろいろなモンスターでふんだんに使っている。
  • 説明書の aptitudes.txt を、スキル適性のコードから自動で作るようにした。
  • インクルードするヘッダファイルを整理し、コンパイル時間を大きく減らした。
  • 固定アーティファクトと特殊アーティファクトが、同じすっきりしたコードの構造を共有するようになった。
