回避 Evasion

英語版 CrawlWiki の記事「Evasion」(0.33 向け、2026-09-29 版)の翻訳です。原文の著者は編集履歴をご覧ください。
この記事は 0.33 の時点の内容で、最新の 0.34 とは違うところがあるかもしれません。

このページはキャラクターの能力値についての記事だ。ブランドについては回避(ブランド)の記事を参照。

回避(よく EV と略される)は、キャラクターやモンスターが近接攻撃、射撃、魔法のビームをかわす能力を表す数値だ。攻撃の当たり外れを決めるときは、対象のその時点の EV でダイスを振り、攻撃側の命中のダイスと比べる。このとき、状況による補正があればそれも加味する。命中のダイスが EV のダイスと同じか上回ったときだけ、攻撃は当たる。

プレイヤーの EV

キャラクターの EV の合計を求める計算は込み入っていて、さまざまなスキルや能力値が関わってくる。

基本の EV

プレイヤーの基本の EV は次のように計算する。 

 10 + size_factor

「体格の係数」(size_factor)は種族の体格で決まる。中くらいの体格で 0 になり、そこから体格が 1 段階小さくなるごとに 2 ずつ増える。[1]

体格 種族 体格の係数
とても小さい スプリガン、フェリッド +4
小さい コボルド +2
中くらい ほかのすべての種族 0
大きい
大きい(胴体は通常の大きさ) 		トロル、鬼
アルマタウル、ナーガ 		-2

一部の変身は、種族による体格の係数を上書きする。

体格 変身 体格の係数
極小 コウモリ、霧化、茸化 +6
小さい 豚化 +2
大きい 大蛇 -2
巨大 竜化 -4

身動きできないとき

麻痺しているとき、石化しているとき、樹化しているときは、EV が次の値まで下がる。 

 2 + size_factor/2 (最低 1 EV)

ほかの要素は一切かからない。ただし、通常の EV のほうがこの値より低いときは、低いほうが使われる。

躱し身

躱し身のスキルは、EV に次のボーナスを与える。 

dodge_bonus = (8 + Dodging × Dex × 0.8) / (20 - size)
armor_penalty = unadjusted_armor_encumbrance - 3
if armor_penalty < 0:
    modifier = 1
if armor_penalty > 0:
    if armor_penalty >= Str:
        modifier = Str / (armor_penalty * 2)
    if armor_penalty < Str:
        modifier = 1 - armor_penalty / (Str * 2)
final_dodge_bonus = dodge_bonus * modifier

防具と盾による EV の減少

基本の EV と躱し身のボーナスを足したあと、防具と盾による EV の直接の減少を差し引く。下に挙げる防具にはそれぞれ「重さの値」(encumbrance rating)があり、これを EV の減少に換算する(換算の式は種類ごとに違う)。

  • 馬甲: -2 EV
  • 胴鎧: -1/225 * encumbrance^2 * (90 - 2 × armour_skill) / (str + 3)
  • 盾: -2/5 * encumbrance^2 / (str + 5) * ((27 - shield_skill) / 27)

補正

EV はさまざまな効果で増減する。これらは上の計算を終えたあとの EV の合計に直接加わり、次の順番で計算される。

「永続的な」効果:

  • 躱し身の指輪は、その値どおりのボーナスかペナルティ(ふつうは +5)を EV に与える。躱し身の指輪を基にしたランダムアーティファクトも同じだ。
  • 一部の固定アーティファクトは、EV にボーナスかペナルティを与える。
  • 斥力場とゼラチン状の体は、そのレベルに応じたボーナスを与える。
  • ルーの信者で、EV を下げる健常の犠牲を捧げた者は、犠牲 1 つにつき -5 のペナルティを受ける。
  • 天狗はレベル 7 になると EV に +4 のボーナスを得る。

倍率:[2]

  • 石像に変身中: -20% EV
  • 絡めとられているか石化中: -50% EV(重ねがけにはならない)
  • 水のマスの中か上にいる水棲の民: +25% EV(最低でも +2)

状態:

  • 酩酊: -5 EV
  • 締めつけ(絡まる木の根によるものを含む): -10 EV
  • 器用強化: +5 EV
  • 反発: 飛び道具に対して +15 EV
  • 軽業の特性: 直前の行動が移動か待機なら +15 EV

最後にかかる状況による補正

近接攻撃に対して:

  • 攻撃してくる相手が見えないとき(つまり相手が透明で、あなたに霊視がないとき)は、その相手に対して EV に -10 のペナルティを受ける。
  • 階段を下りようとしているところを攻撃されると、EV に -5 のペナルティを受ける。

モンスターの EV

モンスターの基本の EV は、モンスターの種類ごとに決まった固定の値だ。この値は防具や装身具、さまざまな状態によって変わる。

命中と EV

攻撃の命中値が 1500(マジックナンバー AUTOMATIC_HIT)以上なら(魔法の矢など)、攻撃は必ず当たる。

それ以外のときは、次の手順で判定する。

  • 2.5% の確率で、攻撃の命中値や防御側の EV に関係なく攻撃は外れる。
  • 2.5% の確率で、攻撃の命中値や防御側の EV に関係なく攻撃は当たる。
  • 0 から命中値まで(両端を含む)の一様乱数を 1 つ作る。
  • 0 から ((2 * (対象の EV)) - 1) まで(両端を含む)の一様乱数を 2 つ作り、その平均をとる。
  • 命中のダイスが EV のダイス以上なら攻撃は当たり、そうでなければ外れる。

変更履歴

  • 0.32 より前は、プレイヤーの EV にかかる倍率は一時的な補正のあとに適用されていた。また、麻痺や不器用のような効果で、「身動きできないとき」の EV のほうが今の EV より高ければ、かえって EV が上がることがあった。
  • 0.27 より前は、30 を超える EV に逓減がかかっていた。adj_EV = 10 + 20 * log(1 + (EV-10)/20log2)。躱し身のボーナスを計算するときの器用にも逓減がかかっていた。
  • 0.25 より前は、器用さの薬で手軽に EV を上げられた。
  • 0.19 より前は、一部の射撃武器に回避のブランドがつくことがあり、EV に +5 のボーナスを与えた。
  • 0.17 より前は、飛んでいる天狗と泳いでいる水棲の民の EV のボーナスは +9 が上限だった。
