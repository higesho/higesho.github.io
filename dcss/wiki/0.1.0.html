リリースノート

これは Dungeon Crawl Reference プロジェクトの、いくぶん実験的なブランチ(コードネーム Stone Soup)だ。あくまでブランチであり、公式の Dungeon Crawl Reference ではないことに注意してほしい。

このバージョンが目指すのは、Dungeon Crawl Reference(実験やパッチのための安定した土台となり、Dungeon Crawl の主なメンテナーが不在の間の穴を埋めることを目指している)をもとに、Brent Ross の 4.1.2 アルファ版などから取り入れた良い機能や、Dungeon Crawl のプレイヤーのコミュニティから出たアイデアを積み上げること、そしてゲームバランスを崩さずに Dungeon Crawl の開発を前に進めることだ。

Stone Soup 0.1 (20060918)

  • 呪文強化の杖は呪文のパワーだけを高め、成功率は上げなくなった。
  • 連鎖する稲妻(レベル 8)が電撃の球体に取って代わった。
  • いくつかの呪文のレベルを変更した(ボルグノールの蘇生、静寂、幻像、精密瞬間移動)。
  • シフ・ムーナの信仰心は、呪文のスキルを訓練したときにしか上がらなくなった。
  • オカワルが矢弾を授けるようになった。
  • 生物感知がいくらか不正確になった。生物感知を使う前に、階層マップの表示が消去される。
  • 輝けるものは、自分のデーヴァが死んでも文句を言わなくなった。
  • 輝けるものが、雷霆の矢の代わりに浄化の炎を授けるようになった。
  • ロッド(打撃のロッドを除く)は魔力を蓄えるようになり、装備したり持ち歩いたりしている間に少しずつ魔力が回復する。
  • 盾が強くなった。
  • 歪曲のブランドが再び登場した。
  • ふつうの毒の吹き矢針に加えて、クラーレ毒の吹き矢針が登場した。
  • 新しくゲームを始めたとき、視界の中にモンスターが生成されることはなくなった。
  • モンスターが、同じ種類のほかのモンスターと場所を入れ替われるようになった。
  • 射撃武器が、獲得の巻物やオカワルの授かり物で手に入るようになった。
  • 火炎と冷気の矢弾が強くなった。
  • 射撃武器にヴォーパルのブランドが付くようになった。
  • 投擲スキルの名前が遠距離戦闘に変わった。
  • 遠距離戦闘のスキルは、矢弾が壊れずに残るかどうかに影響しなくなった。
  • モンスターのドラコニアンとデスドレイクを追加した。ドレイクはすべて 'd' ではなく 'l' で表示されるようになった。
  • ラジャタン、ロッホアバーアックス、ロングボウを追加した。
  • セーブとボーンファイルのバージョン番号を 0.x にしたので、stone_soup では 4.0 のセーブを読み込めない。
  • モンスターが毒素の矢を唱えられるようになった。
  • ナーガの近接攻撃のダメージを少し上げた。
  • ジェリーの穴
  • 飛び道具が強くなった。
  • 発動スキルで最大 MP が増えなくなった。
