PuTTY

英語版 CrawlWiki の記事「PuTTY」(対象の版の記載なし、2024-01-17 版)の翻訳です。原文の著者は編集履歴をご覧ください。
この記事は 古い版 の時点の内容で、最新の 0.34 とは違うところがあるかもしれません。

PuTTY は端末エミュレーターのアプリケーションで、SSH、Telnet、rlogin、生の TCP の各プロトコルのクライアントとして使える。サーバーにログインするのによく使われている。Stone Soup 0.5 より前は、Windows から teraterm や PuTTY で接続すると、テンキーが効かないようだった。PuTTY での回避策として、Settings->Terminal->Keyboard でテンキーの種類を NetHack にする方法がある(そのためのラジオボタンがある)。こうすると、テンキーを押したときに矢印キーの動きではなく vi キーが送られるようになる。あるいは、マクロのファイルにキーコードを書き込んでもいい。ひとつ注意してほしい。NetHack モードではテンキーで入力される文字が実質的に変わるので、テンキーで打ったパスワードは、キーボード上段の数字キーで打ったものとは別物になる(これは CAO や CDO などのサーバーにつないだあと、ゲームを遊ぶためにログインするときの話で、そもそも接続するときの話ではない)。

こうした設定でもテンキーの使い勝手に満足できないなら、Terminal -> Features で「Disable application keypad mode」にチェックを入れてみるとよい。テンキーの +-/*enter が期待どおりに動くようになり、ほかにも直るところがあるかもしれない。ローカル版のように shift-テンキー5 で長い休憩を取れるようにする方法は、Der slinkmeister にもわからない。0.58 のリリースでは Control+テンキーが効かないが、0.60 にアップグレードすれば直り、以前の設定もすべてそのまま引き継がれる。

右クリックするとクリップボードの中身がまるごと入力されてしまうのにうんざりしているなら、Window->Selection->Control uses of mouse でこの機能を切れる。マウスボタンの動作を Windows にすればよい。この機能を切りたくないなら、Ctrl を押しながら右クリックすれば、ふつうのコンテキストメニューが出る。
