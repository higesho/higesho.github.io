巨人の一覧 List of giants

巨人は巨大な人型の生き物で、もっぱら力ずくで戦うが、強力な遠隔攻撃を持つものも多い。巨体のおかげでずいぶん痛めつけられても倒れないが、回避はひどく低く、たいていは攻撃を当てやすい。巨人にはいくつかの種類があり、迷宮の下層に住んでいる。宝物庫や深層ではさらによく見かけるようになる。

巨人の種類

C サイクロプス - 動きが遅く、縄張り意識の強い農耕の巨人。眠りの羊やヤクの群れを守っていて、敵には容赦なく大岩を投げつけてくる。

C エティン - 双頭のオーガをさらに大きく、強くしたような巨人。迷い込んだ冒険者を、2本の巨大な武器で嬉々としてペースト状にしてくれる。

C 炎の巨人 - 火炎のグレートソードを振るう燃えさかる大男。ファイアボールでどこにいようとこちらを焼いてくる。

C 霜の巨人 - 炎の巨人に似ているが、こちらはひんやりクールで、バトルアックスを持っている。

C 岩の巨人 - 山のような怪力を持つ怪物じみた巨人で、強力な土の塊を撃ち込んでくる(実のところ、ただの大岩だ)。

C タイタン - 嵐の魔法を極めた神々しい巨人。

C 鉄の巨人 - とびきり大きな巨人。仲間をこちらへ投げつけてきたり、こちらを仲間のところへ引き寄せたりする。

C 穢れたリヴァイアサン - 永遠にタルタロスをさまよう呪いを受けたアンデッドの巨人。敵をそばから離れられなくして、自分が吐く腐った瘴気の雲の中へ引き込む。

C ジャガーノート - 動きが速く、とてつもなく強い巨人。ただし強烈な一撃を放つたびにひと休みしなければならない。

C 変幻の始祖 - 変身能力者の祖先にあたる、形を持たない太古の存在。こちらに放射の光を浴びせ、死ぬとさまざまなモンスターに分裂する。

C サボテンの巨人 - 砂漠に住む巨人で、召喚によって迷宮に呼び出されることがある。とりたてて力が強いわけでも手が速いわけでもないが、棘がかなり痛い。

ユニーク

C ポリュペモス- ずば抜けて腕のいいサイクロプスの羊飼い。人食いヤクやカトブレパスを手なずける秘訣を知っているのは彼だけだ。

C アンテウス- 巨人のなかでも最大の存在。悪魔の王として、氷の領域コキュートスを治めている。

C チャック- ダンジョンスプリントにだけ出てくるユニークの岩の巨人。混沌の大岩と、おしゃれな帽子が目印だ。

削除された巨人

C 丘の巨人 - 巨人のなかでいちばん小さく、巨大と呼べるかどうかぎりぎりだったが、それでも巨大棍棒の一撃は重かった。0.20 で削除された。

C 『アイアン・ジャイアント』- 錆びついた巨大な大男で、鉄の精霊を呼び寄せて手を貸させた。ダンジョンスプリントにだけ出てきた。0.18 で普通の敵に変わった。
