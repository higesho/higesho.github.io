リリースノート

Stone Soup 0.3.0 (20071031)

おことわり: ここに挙げたのは主な変更だけで、すべての変更を網羅したものではない。

キャラクター

  • 丘ドワーフとエルフの種族を削除した。
  • 神々の末裔は代謝が速くなくなり、能力値が上がりやすくなった。
  • ケンクは足爪のある足で蹴りを放てる。また、荷物が軽ければふつうより速く飛べる。
  • ケンクと水棲の民は、得意な環境にいるときに回避のボーナスを得る。
  • 悪魔の血族は、悪魔の武器を使うとボーナスを得る。

神

  • 新しい神: オークの神、ベオ。
  • 変更された神: ネメレクス、ゾム、ルゴヌ、トログ、エリヴィロン、オカワル。
  • 倒した敵を神に捧げるのに、祈る必要はなくなった。
  • ネメレクスの信者は、アイテムを捧げるのに携帯祭壇が要らなくなった。
  • ネメレクスの信者は、信仰心が上がるにつれて、デッキを操るさまざまな能力を授かる。
  • [1761974] トログに魔法書を焼く能力がついた。
  • [1754125] 怪力と加速の代わりに、トログの御手と戦友の召喚がついた。
  • エリヴィロン: 武器を捧げる代わりに、武器を破壊する能力がついた。
  • オカワルは小さな癒しを失った。
  • 腐った死体は、神が捧げ物として受け取らない。
  • 善の神は、意図しない衰弱を罰しなくなった。
  • アイテムを捧げたときに信仰心が上がったことは、それぞれ違うメッセージで伝えるようにした。

アイテム

  • 新しい矢弾: ジャベリン、スリングの弾、投げ網。
  • 投擲武器に「帰還」のブランドがつくことがある。
  • [1756363] 新しい薬: 耐性の薬。
  • [1744612] 帰還の武器を導入した。
  • [1789869] モンスターが使うところを見たアイテムは、効果がはっきりしていれば鑑定される。
  • アーティファクトの装身具は自動で鑑定されなくなった。代わりに、「はっきりわかる」変化や能力はメッセージで知らせる。
  • [1768865] アイテムを調べるときに、銘を刻むかどうか尋ねるようにした。
  • 所持品の一覧からアイテムを調べても、所持品の画面を抜けないようにした。
  • [1735752] ワンドに、使った回数を自動で銘として刻む。
  • モンスターが使ったアイテムに、自動で銘を刻むようにした。
  • 警告の銘が、説明にあるすべてのコマンドで本当に効くようになった([1795568] !r で巻物を読めないようにできる)。
  • [1793698] アイテムを選ぶメニューで "." を押すと、前に選んだアイテムの次のアイテムの選択を切り替える。
  • [1783003] メニューの並べ替え方を増やし、装身具の並べ替えのバグを直した。
  • 書物店に同じ本が重なって並びにくくなった。
  • [1746014] 'f' で撃つときに、矢弾を順に切り替えるコマンドを追加した。

モンスター

  • 捻れた蘇生で作った忌まわしきものは、アンデッドとして扱われるようになった。
  • オーブを拾ったあとは、モンスターの湧く速さが上がる。
  • バーサークしたモンスターは近くの敵に襲いかかり、仲間への命令を聞かない。
  • あなたが混乱させたモンスターが、自分やほかのモンスターを死なせたときにも、経験値が入るようになった。
  • [1779770] 階段を使ったモンスターは、階段の行き先に合わせて現れるようになった。
  • 'x' で見るときや狙いをつけるときに出るモンスターの説明を短くした。
  • 瓶から出したイフリートは、ずっと消えない。
  • 司祭のミイラと上位のミイラの知能を高くした。

階層

  • ポータルのヴォールトを追加した。具体的にはバザールだ。
  • ラビリンスの見た目が大きく変わった。
  • 岩の階段を脱出ハッチに変えた。
  • 新しい罠: 網の罠。
  • 新しいヴォールトの地図をいくつか追加した。
  • 地獄の入り口でモンスターが湧く速さは、そこにいる時間が長くなるほど下がる。
  • 宝物庫に閉じた部屋ができてしまうのを直した。

インターフェース

  • [1772497] runrest_ignore_monster を使うと、走行、休息、探索のときに遠くのモンスターを無視できる。
  • 会話と物音のチャンネルで休息が中断されないようにした。
  • 周囲を調べたときの情報を、メッセージ履歴に残さないようにした。
  • 情報を示すだけの空腹状態を 3 つ追加した: 飢餓寸前、とても空腹、とても満腹。
  • 自動拾いを賢くする pickup.lua を追加した。
  • アイテムに隠れた罠のための trap_item_brand を追加した。
  • 狙いをつけるときに、ビームの通り道を表示するようにした。
  • 武器でないものを手にして戦おうとすると、警告を出すようにした。
  • 階層間自動移動で、分岐の入口へも移動できるようにした。
  • 長柄武器を使えば、隣の浅い水に潜ったモンスターを Ctrl+方向キーで攻撃できる。
  • Unix で Unicode の記号に対応した。
  • view_max_width と view_max_height のオプションを設定すれば、80x24 より大きい端末で広い表示域を使える。
  • ゲームをやめるときは "Yes" と入力して確認する。

その他

  • Crawl には Lua が必要になった。Lua 5.1 のソースは Crawl のソースに同梱している。
  • モンスター、呪文、地形の説明と、モンスターの台詞をテキストファイルから読み込むようにした。
  • [1777426] 爆発が壁を突き抜けなくなった。
  • 透明化がもっと役に立つようになった。
  • ユーザーの Lua スクリプトに CPU とメモリの使用量の制限を設け、公開サーバーでも安全に使えるようにした。
  • DOS 版の不具合を直した。
  • Crawl が記録するプレイ時間は、1 回の行動あたり最大 5 分で打ち切る。
  • Crawl が dgamelaunch とうまく動くよう、さらに修正を入れた。
