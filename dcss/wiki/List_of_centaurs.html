――オウィディウス『変身物語』第12巻330行(8年)

セントール(と、その親類のサテュロスやヤクトール)は、腰から上が人間で、下が獣の体を持つ人型の混成生物だ。どれも危険な射手で、(ときにはブランド付きの)矢やスリングの弾、クロスボウの矢を、どれだけ離れていても雨あられと撃ち込んでくる。

セントール

c セントール - 数えきれない早すぎる死を招いてきた、恐るべき射手。

c セントールの戦士 - 備えのない英雄を打ちのめす、選りすぐりの射手。セントールの仲間の群れを連れていることが多い。

ユニークのセントール

c ネッソス - 鎧をまとった残忍なセントール。自分を加速させてから、毒液や火炎の矢を獲物に射かけてくる。

サテュロス

c ファウヌス - いたずら好きの山羊人間。呪術で敵を困らせ、矢やスリングの弾を浴びせてくる。

c サテュロス - 率いて戦うファウヌスたちより弓の腕は上で、魔法もいっそう厄介だ。笛でさまざまな戦の調べを奏で、ファウヌスたちを奮い立たせる。

ヤクトール

c ヤクトール - セントールの近い親類で、クロスボウを好む。足の遅さは、正確な狙いと数で補っている。

c ヤクトールの族長 - クロスボウにかけては並ぶ者のない名手。この狙撃手たちは格下のヤクトールの一団を率い、迷宮の奥深くを狩り歩く。

没になったサテュロス

c パン - ユニークのサテュロスとして考えられていたもの。格下の同族が飛び道具の雨でプレイヤーを仕留めるあいだ、プレイヤーの動きを封じる役どころになるはずだった。

変更履歴

  • 0.14 で、ファウヌスとサテュロスが追加された。このとき、パンを加えることも一時は検討された。
