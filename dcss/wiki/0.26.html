主な変更

  • 新しい種族: パレントンガ。
  • 新しい職業: 探索者。
  • 食料と空腹がなくなった。
  • 沼に新しいモンスターがたくさん加わり、ほかにも変更が入った。
  • 遠距離攻撃のセットと自動戦闘のしくみを広げて、呪文、ワンド、能力もセットして撃ったり、自動で狙ったりできるようになった。

モンスター

  • 沼の新しいモンスター:
    • ウィル・オ・ウィスプ。強力な狐火を放つ、この世ならぬ気体。
    • ゴライアスガエル。酸の舌で、離れた敵をなめる。
    • エレイオノマ。木々の間を渡り歩き、木から癒やしを得る沼のニンフ。
    • 膨れた抜け殻。腐ったガスではち切れそうになっていて、破裂する。
    • バニップ。足が速く、強烈な一撃を叩きこみ、叫び声をあげる謎の生き物。
    • 沼渡りの魔女。呪いを投げつけてくる、恐ろしい毒の魔女。
  • 湿地の屍骸の呪文がずっと強力になり、冷気の攻撃も強くなった。
  • 新しい(?)モンスター: 岩石の甲虫。すばやく転がってきて、強烈な一撃を見舞う。
  • 昆虫の記号が整理し直された。
  • ピケルの奴隷は、レムレースに作り直された。ピケルが死ぬと消えるようになった。
  • 棘ガエルは、より本場オーストラリアらしい体験のためにオオヒキガエルに改名された。
  • パンデモニウムの君主が使う呪文と近接攻撃の追加効果の候補が増えた。ときどき危険な雲の輪を生み出すようにもなった。
  • モンスターの血の匂いの察知と巣の振動の察知が削除された。
  • クロコダイル、ヤマアラシ、ヒポグリフ、飢えた幽霊が削除された。
  • プレイヤーが別の階にいる間も、モンスターがプレイヤーのことを忘れなくなった。
  • 攻撃してこない植物、菌類、そのほかの植物のようなもののほとんどは、攻撃を受けると3〜5ターンでしおれるようになった。藪と荊棘は例外だ。
  • 以前は近接攻撃で腐敗させてきたモンスターは、衰弱させる攻撃を持つようになった。

キャラクター

  • 空腹(と食べること)が削除された。
  • 衰弱は、スキルではなく最大 HP を一時的に下げるようになった。腐敗のしくみはなくなった。
  • 新しい種族: パレントンガ。6本の手足と鱗を持ち、転がって突進する哺乳類。
  • 闇エルフの弓の適性が +3 に上がった。
  • コボルドが闇隠れ 3 の変異を持つようになった。視界が狭くなる代わりに、隠密にボーナスがつく(悪魔の血族は闇隠れを得られなくなった)。
  • グールは、肉を食べる代わりに敵を倒すと回復するようになった。時間とともに腐敗することもなくなった。
  • セントールが削除された。
  • 加護のスキル(と吟遊詩人の職業)が削除された。
  • 悪魔の血族の新しい変異: 鋭い鱗と巨大な脳。
  • 変成術師は矢を持って始まらなくなり、初期の魔法書では棒切れの蛇の代わりに人狼の血が入るようになった。
  • 魔術師の職業は「在野の魔術師」に改名され、ダガーを持つようになり、初期の能力値は知力に偏らないものになった。魔術師の以前の能力値は、妖術師が引き継いだ。
  • 暗殺者の職業は「山賊」に改名された。
  • 新しい職業: 探索者。迷宮:5 から、いろいろな逃走手段を持って始まる。
  • 発動術師は、守りのスキルが良くなり、武器のスキルを持たずに始まるようになった。ショートソードと短剣のスキルの代わりに棍棒を持つ。
  • モンスターをアビスへ追放すると、経験値をすべて得られるようになった。
  • 魔力汚染が3倍速く抜けるようになった。
  • 放浪者は、どの発動アイテムを持って始まることもある。
  • 発動のスキルで最大 MP が増えることはなくなった。

アイテム

  • 新しいスカーフのエゴ: 影。影のスカーフは視界を1狭める。これはほかの視界を変える効果と重なる。また、マイナスの呪文強化としても働く。
  • 新しい武器のエゴ: 霊体化。霊体化のエゴは、釘つき巨大棍棒、六尺棒、ラジャタンと、どの種類でも両手持ちのランダムアーティファクトにつく。攻撃が当たると、使い手と並んで戦う幽体の武器を呼び出す。その強さは発動のスキルで伸びる。
  • 新しいブーツのエゴ: 猛進。猛進のブーツを履いていると、敵の方へ向かって動くときに限り、追加の一歩をただで踏み出す。猛進のエゴは、どの種類のアーティファクトの防具にもつくことがある。
  • 新しい発動アイテム: 凝結の風見。経験値で充填される発動アイテムで、敵対するモンスターの周りに雲を生み出す(味方は避ける)。雲の質は発動のスキルで伸びる。
  • 新しいアイテム: 誘引の薬。近くの敵を引き寄せる。
  • 固定アーティファクトの変更:
    • 火蜥蜴の皮鎧は *Rage を与えなくなった。代わりに、rF++、rC--、炎の雲が効かない効果、炎の雲の輪の効果を持つ、炎の呪文強化になった。
    • 鼠の毛皮のクロークは、+Rats から *Rats に変わり、プレイヤーが攻撃を受けるとネズミを呼び出すようになった。
    • ウカド・ムーの杖は、発動によるチャネリングができなくなった。代わりに、発動のスキルによる確率で、呪文の MP の消費を払い戻す。払い戻しが起こると、混乱するか知力が下がることがある(その確率は呪文のコストと発動のスキルで変わる)。
    • 盗賊の外套は、+Fog から *Fog に変わり、プレイヤーが攻撃を受けると霧を生み出すようになった。
    • 魔神棒は大賢者を失った代わりに、唱えた呪文がどれでも吸血になることがあるようになった。生き物に与えたダメージの分だけ唱えた者が回復する。
    • 耐性の盾は、+2 のカイトシールド {rF++ rC++ MR++} になった。
    • 番人のグレイブは、霊体化と電撃の両方のエゴを持つようになった。sInv と +Rage はなくなった。
    • 星明かりのクロークは *Dazzle を得た。回避に成功すると、目くらましの閃光の呪文のように、ときどき敵の目をくらませる。rElec と rC+ はなくなった。
    • 力の剣は +5 のヴォーパルになり、ときどき強力だが命中率の低いダメージの光線を撃つようになった。その確率はプレイヤーの今の HP で決まる。
  • 幻影の鏡と獣の匣は、経験値で充填されるようになった。
  • 変化のワンドで狙うと、モンスターが何に変わりうるかが表示されるようになった。
  • 護符は(防具と同じく)身につけるのに時間がかかるようになり、多くの護符でなじむしくみがなくなった。信仰、再生、魔力再生は、付け替えたときの不利をそのまま残している。
  • 馬甲は1種類のアイテムにまとめられた。
  • 大地の杖はダメージが上がったが、AC の影響を3回受ける、破片と同じ扱いになった。妖術の杖は、抵抗できない追加ダメージを与える。このダメージは AC で軽減される。
  • アイテムの山は、見ただけで中身がすべてわかるようになった。
  • 急所攻撃の薬、雲のワンド、活力の杖、召喚の杖、魔術の杖が削除された。

分岐・環境

  • 沼の階が小さくなり、弱いモンスターの多くが出なくなった。
  • 赤インプと影のインプが、迷宮でずっと珍しくなった。代わりに白インプとウフェツバスが出る。
  • シャドウとワイトが地下墓地の出現表からはずれ、代わりに空飛ぶ頭蓋骨、死人使い、レイスが入った。
  • 蜘蛛の穴ぐらが静かになった。
  • 一か所にあまりに長くとどまるプレイヤーは、ゾットの悪意ある力に見つかるようになった。
  • 試練場のモンスターは起きた状態で生成されるようになり、ミノタウロス以外は戦利品を拾わなくなった。
  • 網の罠は消えなくなり、網は必ず壊れるようになった。

呪文

  • 加護のスキルと系統が削除された。
  • オゾクブの鎧は氷の魔術だけの呪文に、俊足は風の魔術だけの呪文に、死のとば口は死霊術だけのレベル9の呪文になった。苦痛の傷痕は死霊術だけの呪文になり、効果が続く間は武器を手放せなくなるうえ、騒音に加えて魔術強化のマイナスもかかるようになった。
  • 戦闘球は妖術だけの呪文になった。狙い方も調整され、魔火花の従者以外のすべての妖術の呪文に反応するようになった。
  • 殺戮の歌は変成術の呪文になり、人狼の血に改名された。騒音はいくらか小さくなった。
  • スケルトンの造成と死霊の蘇生で作ったものは、強さが呪文の威力で伸びるようになった。スケルトンの造成には威力の上限がある。どちらも作ったものの寿命が短くなった。また、近くに死体がないと唱えられなくなった。
  • スケルトンの造成は、一番近くの骸骨を動かすようになり、死体の上に立つ必要がなくなった。
  • 凍てつく城壁は、プレイヤーが動くと効果が切れるようになった。
  • 死の霊媒術の幽体は持続時間が短くなり、死の霊媒術が切れると消えるようになった。
  • スカラベの寄生のスカラベは持続時間が短くなった。
  • ヴァンパイアの吸血のダメージが、回復できる量で制限されることはなくなった。
  • エリンギャの毒沼は、半径4の範囲で、隣に固い地形がないすべてのマスに沼を作るようになった。
  • 半獣の躰は兜とブーツを溶けこませるようになり、ランダムに選ぶのではなく、角と足爪の両方を2レベルずつ与えるようになった(オクトポードは棘付き触手のまま)。
  • 放射の光は、モンスターの AC で軽減されるようになったが、ダメージが少し上がった。
  • アリステイアの酩酊は、見えている範囲に効く相手がいないときに確認を求めるようになり、成功すれば必ず酩酊をかけるようになった。威力の上限も上がった。
  • 魔術の球雷の、呪文の威力による伸び方が単純になった。
  • 光線の呪文とワンドは、何かに当たっても射程が縮まなくなった。
  • 一時的な味方は、あなたが階を離れるとすべて消えるようになった。
  • 転位術の呪文の失敗は、移動×をかけるようになった。転位だけでなく歩くこともできなくなる。
  • 解放のオーラ、暗闇の喚起、魔力の装填、招来、炎の円環、ゴルブリアの帷子、幽体の武器、棒切れの蛇、胡蝶の召喚が削除された。

神

  • ゴザーグは、信仰したときに水薬の陳情をただで1回させてくれることはなくなった。
  • ネメレクスがデッキを贈り始める信仰心が高くなった。
  • ネメレクスの縦穴のカードが削除され、放浪のカードで自分がアビスへ追放されることはなくなった。

インターフェース

  • 「セット」の機能が一般化され、呪文、発動アイテム、能力もセットできるようになった。射撃の画面で、セットできるどの行動でも狙えるようになり、セットした行動は shift+tab/p で自動で撃てる。autofight_throw のような、今までの自動戦闘の遠距離攻撃の設定も、新しくセットできるようになったものに対応した。] キーで、直近にセットした2つの行動を入れ替えられる。新しく加わったオプションや変わったオプション(autofight_throw、autofight_stop、automagic_stop、fail_severity_to_quiver、launcher_autoquiver、fire_order)について詳しくは、オプションの案内を参照。関係するキー割り当ての一覧は、マニュアルの4章の「Attacking and firing」の節を参照。
  • 射撃武器は、セットとは別に撃てるようになった。v で狙う(間合いのある武器と同じ)か、普通の自動戦闘のコマンドで自動で狙える。
  • 呪文と能力に、どのマスが効果を受けるかを示す固定の照準表示が加わった。唱えている間にどれを表示するかを設定する新しいオプション force_targeter も加わった。
  • プレイヤーのワンドのダメージ、呪文のダメージ、呪文の命中率が画面に表示されるようになった。
  • xv でモンスターを調べると、今の武器での命中率が表示されるようになった。
  • xv で、モンスターの呪文のダメージが表示される。
  • 気になるものがいくつもあるマスを調べると、選ぶためのメニューが出るようになった。
  • 「足元の山を見る/拾う」のキー ; を2回押すと、安全でない状況でも強制的に自動拾いできるようになった。
  • ^x の説明の画面が、どの狙いの確認からでも見られるようになった。狙っている間に使うと、射程内の有効な目標を一覧にする。
  •  ! の画面から、どこからでもどの床にも注釈をつけられるようになった。
  • 呪文の威力が、最大威力に対する割合で表示されるようになった。
  • マクロの更新: マクロとキー割り当ては、ゲーム中に ~ のメニューで見られるようになった。RC ファイルのキー割り当ての設定で、エスケープコードが使えるようになった。
  • 変更されたオプション: travel_open_doors に、自動移動の間に扉を開けるのをなるべく避ける設定が加わった。
  • 新しいオプション: travel_one_unsafe_move。true にすると、自動移動はいつもの安全確認をする前に、目的地へ向かって1歩だけ動くようになる。
  • 新しいオプション: monster_item_view_features。正規表現のリストのオプションで、このリストのパターンに合う地形が ^x の説明の画面に表示される。
  • 新しいオプション: always_show_zot。有効にすると、ゾットに見つかるまでの残り時間を、残り1500ターンを切ったときだけでなく常に表示する。
  • 新しいオプション: tile_overlay_col と tile_overlay_alpha_percent。ローカルのタイル版で、メッセージのウィンドウの見た目を設定する。

Lua

  • 3つの新しいフック chk_ability_choice、chk_spell_choice、c_message を使って、能力と呪文のメニューの確認に答えたり、メッセージに反応したりできるようになった。
  • 呪文、アイテム、能力を狙って撃つための新しい API が導入された。キーを送るよりも壊れにくい方法だ。Lua の関数 crawl.do_targeted_command、spells.cast、item.fire、you.activate_ability、you.quiver_valid、you.quiver_enabled を参照。
  • ほかの新しい関数: you.memorise(名前を指定して呪文を覚える)、spells.power_perc(呪文の威力を割合で得る)

リリース 0.26.1

0.26.1 はバグ修正の更新で、2021年2月2日にリリースされた。

  • 混乱中に ctrl を押しての攻撃が、また使えないようになった。
  • コンソール版の表示のちらつきが減った。
  • 網の罠から網を無限に得ることはできなくなった。
  • ヴォールトの配置のバランスをいろいろ調整し、テレポートで閉じこめられる小部屋を修正した。
  • ほかに 95 件の修正、調整、文章の手直し、インターフェースの改善。
