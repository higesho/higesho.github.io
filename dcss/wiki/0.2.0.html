バージョン 0.2.0 0.2.0

英語版 CrawlWiki の記事「0.2.0」(対象の版の記載なし、2012-12-21 版)の翻訳です。原文の著者は編集履歴をご覧ください。
この記事は 古い版 の時点の内容で、最新の 0.34 とは違うところがあるかもしれません。

この記事は Crawl の過去のリリースについてのものだ。最新版を含むほかのバージョンについては、Stone Soup のバージョンの一覧を参照。

0.2.0 は Dungeon Crawl Stone Soup の古いバージョンで、2007年4月1日にリリースされた。

リリースノート

Stone Soup 0.2 (20070401)

  • セーブファイルとボーンズファイルの形式が変わり、0.1.x とは互換性がない。
  • ゲームのチュートリアルを追加した。
  • ヴォールトと特殊な階の構造を増やした。
  • 新しい回避の仕組み(4.1.2 から取り入れた)。
  • 迷宮の概要とキャラクター情報の画面を作り直した。
  • 狙いをつける画面のキー割り当てを変えた。
  • 'v' でモンスターやアイテムなどを調べ、'?' でヘルプを出す。
  • -macro オプションで指定するのは、マクロのファイルではなくディレクトリになった。
  • アイテムの色を変えた。
  • 迷宮の深い階には、プレイヤーの幽霊が複数出ることがある。
  • 打撃のロッドにも魔力の蓄えがつくようになった。
  • 毒の塗られていない吹き矢針と、猛毒の吹き矢筒を削除した。
  • アイテムの記録の検索で、祭壇やポータルも見つかるようになった。
  • 変異と種族の能力を整理した。
  • シフ・ムーナは信仰心が上がると贈り物を授ける。シフ・ムーナの信者は祈る必要がない。
  • HD の低いモンスターを倒しても、信仰心は得にくくなった。
  • パンデモニウムの悪魔が魔法の矢しか覚えないのを直した。
  • キャラクターの名前に空白、ハイフン、ピリオドを使えるようになった。Unix では名前の最後を数字にすることもできる。
  • ビームの命中の計算を調整した。
  • ツキマーの舞踏で動かした武器は、自動拾いでは投げたものとして扱うようにした。
  • エラーメッセージは curses の後始末のあとか初期化の前に出すようにして、ユーザーがエラーを読めるようにした。 :-)
  • オレンジ色の彫像の攻撃速度を下げた。
  • Windows 版のビルドで SHORT_FILE_NAMES を使わなくなった。
  • ゲーム内のヘルプブラウザ。
  • パンデモニウムでも欲張りな自動探索が使えるようになった。
  • アイテムの記録で、アイテムの銘も記録するようになった。
  • アイテムが重ならないバグをたくさん直した。
  • アーティファクトは、(v) で調べたときにアーティファクトだと説明されるようになった。
  • 錬金術師の帽子は、兜ではなく本物の魔術師の帽子になった。
  • 鑑定しても空の銘が消えないのを直した。
  • モンスターの恐怖のふるまいがおかしかったのを直した。
  • 店で買い物をするときに確認を求めるようにした。
  • 固定アーティファクトのいくつかに小さな調整を入れた。
  • 美食家の、汚染された肉をきれいな肉に変える効果も、段階的に効くようになった。
  • 捜索の効果を高めた。
  • 新しい神。
  • 甲冑スキルの鍛えられ方を調整した。
  • 完全な草食になるのは、その変異がレベル 3 になったときだけになった。
  • 解体を少しずつ進められるようになった。
  • 棒切れの蛇で毒の矢を使うと、以前よりヘビが出やすい。
  • バーサーク中は買い物ができない。
  • モンスターの移動のバグをいくつか直した。
  • スプリガンは代謝が遅く、食料を多めに持って始まるようになった。ただし草食だ。
  • 暗殺者は、クラーレ毒の吹き矢針を少し持って始まることがある。
  • ロッドが出やすくなった。
  • 走行と休息でメッセージによる中断を無効にしているなら、stop_travel のメッセージで走行と休息も止められる。
  • モンスターが視界に入ったときのメッセージの扱いを改善した。
  • 信仰心が十分あって飢えているときは、ジンが確実に食べ物をくれる。
  • 自動移動が、潜っているモンスターに邪魔されなくなった。
  • 透明なモンスターの攻撃が外れても、自動移動は止まらなくなった。
  • 瞬間移動やテレポートをしたモンスターが、プレイヤーのいるマスに降り立つことはなくなった。
  • アビスへの追放でクラッシュするのを直した。
  • モンスターの耐性に、ランダムアーティファクトの効果が反映されないことがあった。
  • travel_delay = -1 のときの扱いを改善した。
  • 衰弱や地獄の業火を使うモンスターは M_EVIL となり、浄化の炎でダメージを受ける。
  • モンスターを調べたとき、麻痺していればそれを表示する。
  • 所持品のメニューに出す運べる重さは、絶対的な上限ではなく、鈍重にならずに運べる上限になった。
  • 飛んでいるモンスターも機械仕掛けの罠を避けなくなった。
  • 祈っている最中に祭壇へ落としたアイテムは、捧げ物になる。
  • ジェリーはアーティファクトを食べられなくなった。
  • delay_message_clear を有効にすると、スクロールするメッセージ欄を使う。
  • 彫像が動き回ることがあるバグを直した。
  • 武器に一時的に苦痛のブランドをつける呪文「苦痛の傷痕」を追加した。
  • 巻物の名前が重複していたのを直した。
  • 友好的なモンスターがプレイヤーから逃げないようにした。
  • 生物探知で、モンスターの正体がノートに漏れていたのを直した。
  • 大きな端末で階のマップがクラッシュするのを直した。
  • no_dark_brand の既定値を true にした。そうしないとこのオプションの存在に気づきにくく、しかもこれで解決する問題は Unix の端末ではありふれているからだ。
  • 黒や暗い灰色のマスにカーソルを描けない端末のために、擬似的なカーソル(use_fake_cursor = yes)を追加した。
  • おぞましきものの召喚で呼んだものは、一時的な召喚物になった。
  • モンスターの解放の宣誓を弱めた。
  • 飛来物の阻止の効果を下げた。
  • 見えざる恐怖は電撃に耐性を持たなくなった。
  • 欲張りな自動探索は、ミミックを化けているアイテムと同じように扱うようにした。
  • 迷宮:1 では、閉じた入口のヴォールトがある場合を除き、上り階段から少なくとも 1 つの下り階段にたどり着けるようにした。
  • ヒドラはほかのモンスターに対しても、攻撃をすべて繰り出すようになった。
  • ヒドラと戦うモンスターも、ふさわしい武器や爪を持っていれば首を切り落とせる。
  • 階層間自動移動で、分岐の入口と出口をより賢く扱うようにした。
  • 特殊な階を試すため、ウィザードモードに好きな階へ一瞬で移動する &~ を追加した。
  • message_colour オプションで、パターンに合うメッセージに個別に色をつけられる。
  • 仲間の毒や、ダメージを与える雲で死んだモンスターを、正しく巻き添えの殺害として扱うようにした。
