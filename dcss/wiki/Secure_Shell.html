Secure Shell

英語版 CrawlWiki の記事「Secure Shell」(対象の版の記載なし、2022-04-13 版)の翻訳です。原文の著者は編集履歴をご覧ください。
この記事は 古い版 の時点の内容で、最新の 0.34 とは違うところがあるかもしれません。

Secure Shell(SSH)は、ネットワークでつながった2台の機器のあいだで、安全な通信路を使ってデータをやりとりするためのネットワークプロトコルだ。Secure Shell は圧縮に GNU ZLIB(LZ77)を使う。圧縮すると帯域の消費が減り、CPU の負荷との兼ね合いで、全体としては速くなる。多くのオンラインサーバーが対応している(サーバーと SSH 鍵の一覧)。

*NIX を使っていて、SSH のメインのログインで毎回パスワードを打つのに飽きたなら、sorear の $HOME/.ssh/config をコピーするといい。
