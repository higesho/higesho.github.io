Windows / Android

動かし方

対応環境Windows 10 / 11（OpenGL 4.6 対応が必要です）／ Android 13 以降（arm64）
WindowsZIP を任意のフォルダへ展開し、その中の HengbandHd2d.exe を実行します。必ずそのフォルダを作業ディレクトリにして起動してください（assets/ と lib/ を相対で読みます）。
AndroidAPK を端末に入れて開きます。ストアの外からの配布なので、提供元不明のアプリのインストールを許可する必要があります。
VR モードVirtual Desktop から実行します。
ゲームパッドXInput 対応。Xbox コントローラなどを繋ぐと十字キーで移動、A で決定、B で戻る、Select で機能メニューが開きます。
実行中のキーF10 = 機能メニュー ／ F9 = 画面の作り ／ F8 = サブパネル ／ F7 = 一人称の出入り ／ Alt + Enter = 全画面と窓の切り替え

最初にブロックを解除する（Windows 版）

ダウンロードした ZIP を展開しただけでは、Windows が「他のコンピューターから取得したファイル」と見なして実行を止めることがあります。

HengbandCore.exe と HengbandHd2d.exe を右クリックして「プロパティ」を開き、全般タブのいちばん下にあるセキュリティの「許可する」にチェックを入れて OK を押してください。2 つとも必要です。

Windows / Android

Running it

RequirementsWindows 10 / 11 (OpenGL 4.6 required) / Android 13 or later (arm64)
WindowsUnzip it anywhere and run HengbandHd2d.exe from inside that folder. Start it with that folder as the working directory — assets/ and lib/ are read relative to it.
AndroidPut the APK on your device and open it. It is distributed outside the store, so you need to allow installing apps from unknown sources.
VR modeRun it from Virtual Desktop.
GamepadXInput. Plug in an Xbox controller and the D-pad moves, A confirms, B goes back, and Select opens the function menu.
KeysF10 = function menu / F9 = layout / F8 = sub panels / F7 = enter and leave first person / Alt + Enter = fullscreen or window

Unblock the files first (Windows)

Unzipping the download is not always enough. Windows may decide the files came from another computer and refuse to run them.

Right-click HengbandCore.exe and HengbandHd2d.exe, open Properties, tick Unblock at the bottom of the General tab and press OK. Both files need it.
